# Lexicon

How a recurring problem was solved here, so nobody pays for the same lesson
twice.

```bash
toolbox/lexicon.py search checkstyle
toolbox/lexicon.py add --key some-key --title "..." --tags build
```

Every entry here cost somebody real time while this repository was being built.
None of them is a general truth about software; they are facts about *these*
tools at *these* versions, which is exactly the kind of thing that is expensive
to rediscover and cheap to write down.

**This is the only part of the harness that makes the repository better over
time.** Gates stop bad things escaping. The lexicon stops the same afternoon
being spent again.

Search before deriving. Add before finishing.
